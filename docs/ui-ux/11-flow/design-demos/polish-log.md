# 许愿机页设计稿 · 打磨记录

## 第 1 轮（三方向初稿 → 首轮打磨）

首轮截图（`dir-*.png` v1）逐张看后，记下最伤的三处并修：

### 三版共同

1. **下半屏空白没有构图意义**：内容全挤在上半，按钮被 `margin-top:auto` 吊到底边，读起来像"页面没填满"，不是留白。
   改成：主内容紧接排布（生成物品紧跟模块区），空白改由**底部规则小字**收束（真实规则文本），按钮紧跟其所在内容块。
2. **`M̄` 的 bar 丢失**：组合字符 `M̄` 在中文衬线字体里渲染成 `M`。
   改成 CSS `text-decoration:overline`，三版一致。
3. **中点连接装饰**：`·` 被用作分句符号（模板装饰）。内容里的 `排除 · 旧木凳` 是**模块名本身**，保留；句子层面的中点改成全角空格或逗号。

### 单版追加

- **dir-1**：顶栏 `原石` 组缺分隔 → 加 1px 竖线；干员卡 `dl` 行距过密 → 改 `kv` 行 + 细分隔线，按钮紧跟；读数与按钮之间加 header 分隔。
- **dir-2**：竖排栏题原本贴在分栏线上，**两栏的标记撞在一起**（先修成 `left:-34px` 导致飞出画布，再修成 `right:4px` 与相邻栏重叠）。最终改为**贴在各栏右内侧**（`right:24px`），成为三枚独立的页码式标记；升级印章太窄挤成三行 → 加宽到 92px 两行。
- **dir-3**：中栏上重下空 → 把 `Lv.1` 巨字移到中部当图形元素，条款与按钮下移紧跟；右栏"原石"标签与数字错位 → 改成上标签下数字左对齐，升级按钮紧跟；信息区与开启区之间加细线切分。
