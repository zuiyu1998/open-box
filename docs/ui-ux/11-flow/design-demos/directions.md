## 2. 六张方向卡

### 候选 1 ｜最佳设计师 A｜Paula Scher（Pentagram）
- **借的**：把字当形状——巨号数字压住版面、色块分区、印刷网格的粗细反差；不用细线装饰，层级全靠字号与色块。
- **主角素材**：巨号「15」与「≈1.29」（数字即图形）。
- **骨架**：赭红大色块占左三分之一，三个开启按钮横排成色块带。
- **胆量**：中栏做成炭黑整条，与赭红、米白三等分，硬边界。
- **form 来自内容**：许愿机的两件事就是"还剩几次"和"值得开吗"，所以让 15 与 1.29 成为画面最大的东西。

### 候选 2 ｜最佳设计师 B｜服部一成
- **借的**：极简字形、大留白、细到几乎看不见的分隔线、一处朱色打破安静。
- **主角素材**：汉字标题本身的字形（许愿机三个字放大）。
- **骨架**：上重下轻，左栏只剩一条竖线串起三段。
- **胆量**：整个左栏只有三行字 + 三个位子方块，其余留白。
- **form 来自内容**：镶嵌只有 3 位，位子少得像"摆三个东西"，留白正合适。

### 候选 3 ｜现实参照 A｜《Hades》(Supergiant Games, 2020) 的暖色面板语言
- ⚠️ **未联网核实**（本环境 WebSearch 不可用），仅凭对该作品的认知借用其"深暖底 + 铜金细框 + 衬线标题 + 分栏面板"的面板气质，**不复制其任何具体图形**。
- **借的**：深褐底上的铜色细分隔线、衬线标题配无衬线标签、按钮的压印感。
- **主角素材**：三个位子方块与仪表读数（大字琥珀）。
- **骨架**：左右各一块浮起面板，中栏是立牌式干员卡，三个开启按钮竖排。
- **胆量**：右栏两个读数做成"仪表盘"，字号拉到 96px。
- **form 来自内容**："许愿"是仪式动作 → 深色+铜光比亮底更像一台要投币的机器。

### 候选 4 ｜现实参照 B｜《Pentiment》(Obsidian, 2022) 的木刻／手抄本语言
- ⚠️ **同上未核实**，只借"墨线 + 米黄纸 + 朱红批注"的手感。
- **借的**：细墨线版框、旁注小字、印章式按钮。
- **主角素材**：朱红印章块（开启全部）。
- **骨架**：三栏用竖线分隔，栏目标题竖排。
- **胆量**：结果行做成"引文"，朱色下划线。
- **form 来自内容**：盲盒像"卷宗"，镶嵌像"批注"，与收集/图鉴的叙事同源。

### 候选 5 ｜秒数轮盘｜东亚 1 号：吕敬人 书籍工艺
- **来源**：`assets/style-specimens/east/01-lu-jingren-bookcraft.jpg`（**已亲眼看**）。
- **借的**：暖纸 #EDE0BC、墨黑、朱批三色；**竖排栏目标题 + 细线版框 + 大留白**；页码式页脚；印章块。
- **主角素材**：竖排汉字与朱色旁注。
- **骨架**：三栏以竖线切分，右栏读数用"旁注"排法（小字朱色标签 + 大字墨色数值）。
- **胆量**：三个开启按钮做成朱色票券，主按钮是印章。
- **form 来自内容**：这是"许愿机"，许愿=题签；竖排与朱批把设备面板变成一页可读的"签文"。

### 候选 6 ｜秒数轮盘｜网页 5 号：纯 CSS 几何插画（Pure-CSS Art）
- **来源**：`references/design-styles.md` 网页风格库第 5 条（Lynn Fisher 谱系）。
- **借的**：用 CSS 几何形画出"机器"——铜环、光尘、刻度，作为画面主角。
- **主角素材**：程序化绘制的许愿机本体（同心圆 + 刻度 + 光锥）。
- **骨架**：中央放机器本体，三栏内容围绕它分布。
- **胆量**：整屏一块暖橙渐变背景 + 机器悬在中间。
- **form 来自内容**：它确实是一台机器，值得被画出来。

## 3. 挑三张做完整版（标准：单看够好 / 彼此不同 / 不撞账本 / 不过头）

| 入选 | 理由 |
|---|---|
| **候选 3（暖褐铜光）** | 游戏 UI 同媒介里最贴的一组手感；深色暖调，与"投币许愿"的仪式感一致；信息密度承载得住 |
| **候选 5（暖纸朱批）** | 骨架与 3 完全相反（亮底、竖排、细线），暖色语境里的另一种极致；有本地样张可对照，还原有据 |
| **候选 1（赭红海报）** | 第三个体质：色块与巨号数字，无衬线强对比；把"15 / 1.29"变成主角，和 3、5 都不撞 |

**备选（没做完整版，看中可补）**：候选 2（留白极简）、候选 4（木刻手抄）、候选 6（CSS 几何）。三版都没选它们，是因为与入选三版同属"亮底安静"或"道具化"，会让三版挤在一个家族里。
